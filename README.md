# Catálogo comunitario de Códice Studio

Este repositorio no tiene código: solo guarda Issues.

- `[skill] usuario/repo/ruta`: ancla de una skill registrada. Sus reacciones 👍 son los votos.
- `[result] ...`: resultado reportado ("funcionó con el modelo X").

Lo lee y escribe [Códice Studio](https://github.com/SuarezCaceres/ai-skills-studio). Guía de puesta en marcha: `docs/catalog-setup.md` de ese repo.
